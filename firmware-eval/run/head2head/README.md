# head2head - ctadl-souffle vs ctadl-rs on firmware - DO-NOT-MERGE

The experiment described in `../../../EXPERIMENT.md`; the write-up, including how
to reproduce every number and the graph, is `../../../EXPERIMENT-summary.md`.

| Path | What it is |
|---|---|
| `corpus.json` | The 5 firmware binaries, and why those 5 |
| `models/build_models.py` | Builds the ONE shared model set both engines run with, from a single source of truth |
| `models/shared-{index,query}.{rs,souffle}.json` | Generated. Propagation models (index) and sources+sinks (query), in each engine's syntax |
| `env.sh` | Generated by `nix develop .#head2head`; pins both tool paths and `GHIDRA_HOME` so a campaign does not re-evaluate the flake per job |
| `run_one.py` | One engine, one binary, three phases, guarded by a wall timeout and a memory cap; records the metrics |
| `campaign.py` | Runs the whole corpus, both engines, sequentially; resumable |
| `controls.py` | Configuration control: both engines over Operation Mango's synthetic test binaries, to rule out "one engine was handed a model set it cannot use" |
| `analyze.py` | Aggregates into `results/aggregate.json` and `results/TABLE.md` |
| `plot.py` | Draws `results/head2head{,-dark}.png` |
| `results/` | Raw data: one JSON + one SARIF + three logs per engine per binary |

`run_one.py` deletes each job's store/import tree once its size has been
measured — one souffle `ctadlir.db` for a firmware binary is ~200 MB, and the
whole campaign is 1.2 GB of it. Set `KEEP_ARTIFACTS=1` to keep them for a
post-mortem.

## Run it

```sh
nix develop .#head2head          # both engines + one Ghidra
cd firmware-eval/run/head2head
python3 models/build_models.py   # regenerate the shared models (checked in)
source env.sh
python3 campaign.py              # ~6 min for the 5 binaries, both engines
python3 controls.py
python3 analyze.py
python3 plot.py
```
